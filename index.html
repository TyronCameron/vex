vex

The embeddable, local-first, markdown-based task system. Every task is a plain-text file, every project keeps its own .vex folder, and there is no server, no daemon and no account.

rocket_launch Get started code View on GitHub

Open source, MIT licensed. Runs on LuaJIT, so it runs on a potato.

Tasks as plain text

vex keeps your tasks next to your code, in files that any editor, script, git hook or AI agent can read and write.

description

Markdown files

Every task is a markdown file with YAML frontmatter. Open it in your editor, link it in Obsidian, diff it in git.

folder_open

Lives in your project

Each project keeps its own .vex folder, like .git. Commit the tasks, ignore the index, and git does the syncing.

filter_alt

Focuses

Saved, composable queries. Filter, fuzzy-match, walk trees and dependencies, group, order and number, then act on the result.

dashboard

Views

Tables, CSV, JSON, kanban boards, project statistics and a dependency view for any single task.

account_tree

Opinionated task types

Abstracts group work, explorations mark open questions, decisions pick a path and atoms get done.

extension

Extensible

Add task types, transients, recipes, focuses, views and event hooks with a Lua file in .vex, no build step required.
